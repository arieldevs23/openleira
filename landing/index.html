Skill per proyek

Aturan kerja disimpan sebagai file SKILL.md di tiap proyek, sehingga agent membaca konvensi proyek itu sebelum mengubah kode.

toko-apiSKILL.md
---
name: migrasi-db
description: Aturan menulis migrasi
---
- Buat file migrasi baru, jangan ubah yang lama.
- Setiap kolom foreign key diberi indeks.
- Jalankan test sebelum menandai selesai.

Workspace AI Sedang dibangun

Satu proyek diperlakukan seperti workspace, dengan tim agent yang bekerja berfase. Fitur ini sudah berjalan di staging.

  1. Task masuk ke Orchestrator.
  2. Planner menyusun rencana dan urutan tim.
  3. Tim bekerja sesuai rencana, hasil diteruskan antar tim.
  4. QA/Audit memeriksa, lalu Orchestrator merangkum ke user.

Model dipilih per agent, tim bisa ditambah sendiri.

Cara pasang

Syarat minimum: Ubuntu 22.04+, Debian 12, macOS, atau Windows lewat WSL2, dengan 2 vCPU, 4 GB RAM, dan Node 20.

curl -fsSL https://openleira.online/install.sh | bash

Segera Installer satu baris ini sedang disiapkan dan belum bisa dijalankan.

  1. Siapkan mesin

    VPS Ubuntu atau Debian, atau mesin lokal Linux, macOS, maupun Windows dengan WSL2.

  2. Jalankan installer

    Perintah di atas memasang OpenLeira beserta layanannya di mesin itu.

  3. Buka di browser

    Buka alamat server, lalu buat akun pertama. Akun ini menjadi admin server.

  4. Hubungkan agent

    Sambungkan Claude Code, Codex, OpenCode, atau Cursor Agent yang sudah dilanggani.

Login memakai username dan password lokal. Tidak ada akun Google, GitHub, atau layanan pihak ketiga lain yang terlibat.
