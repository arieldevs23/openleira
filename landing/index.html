Masuk

Workspace AI yang berjalan di server sendiri

Jalankan Claude Code, Codex, atau OpenCode dari browser, dengan server dan langganan milik sendiri.

Masuk Lihat cara pasang

Open source. Bukan model AI baru. Bawa langganan AI sendiri.

Fitur

Workspace, bukan model
Menjalankan agent AI dari langganan yang sudah dimiliki.
Server sendiri
Berjalan di Ubuntu atau Debian, pada VPS maupun mesin pribadi, tanpa hosting dari OpenLeira.
Akses dari mana saja
Buka dari browser desktop atau ponsel, sementara sesi tetap berjalan di server.
Provider bebas
Mendukung Claude, Codex, dan OpenCode, dengan OpenRouter menyusul.

Kantor AI Sedang dibangun

Satu proyek dikerjakan beberapa agent dengan peran berbeda. Koordinator membagi tugas ke tiap divisi dan menyatukan hasilnya.

Proyek Koordinator
  • Planner
  • Desain UI/UX
  • Backend
  • Security
  • QA/Audit

Cara pasang

Ubuntu 22.04+ atau Debian 12, 2 vCPU, 4 GB RAM, Node 20.

  1. Siapkan server Ubuntu atau Debian dengan akses SSH.
  2. Jalankan installer di server. 
    curl -fsSL https://openleira.online/install.sh | bash

    Installer sedang disiapkan.

  3. Buka alamat server di browser.
  4. Hubungkan akun Claude, Codex, atau OpenCode yang sudah dimiliki.

Masuk dengan Google, GitHub, atau email.

Tentang

OpenLeira dibuat di Indonesia dan dirilis sebagai open source dengan lisensi GPL-3.0. OpenLeira tidak menjual token dan tidak menyimpan kunci API di luar server pengguna.
