Tim agent AI di komputer sendiri

Tulis kerjaannya, koordinator membagi tugas ke tim agent, dan QA memeriksa hasilnya. Untuk kode, konten jualan, laporan keuangan, sampai pemberkasan.

Download & pasang Lihat fitur

Open source. Bukan model AI baru. Bawa langganan Claude, ChatGPT/Codex, Cursor, atau OpenCode sendiri.

Unduh

Pilih cara pakainya

Komputer Windows

Aplikasi Windows

Satu installer, server-nya sudah di dalam. Klik dua kali, ikuti wizard, langsung bisa dipakai.

Download OpenLeira-Setup.exe

Windows 10/11 64-bit · gratis · semua versi

Kalau muncul “Windows protected your PC”, pilih More info lalu Run anyway. Installer belum ditandatangani.

Server, Linux, macOS, WSL2

Lewat terminal

Butuh Git dan Node.js 22+. Perintah ini mengunduh, membangun, lalu menyalakan OpenLeira di port 3001.

curl -fsSL https://openleira.online/install.sh | bash

Lalu buka http://localhost:3001 atau alamat server di browser.

II · Fitur

Yang sudah bisa dipakai

  1. I

    Tim AI per workspace

    Koordinator menyusun rencana dan membagi tugas ke tiap tim. Satu tim pegang satu tugas sekaligus, tahu kerjaan lain yang sedang jalan, dan QA meminta revisi kalau hasilnya kurang.

  2. II

    Tampilan Simpel

    Empat langkah: hubungkan AI, taruh bahan, tulis kerjaan, ambil hasil. Model tiap anggota tim dipilihkan otomatis, dan pertanyaan koordinator dijawab di tempat.

  3. V

    Empat provider

    • Claude Code
    • Codex
    • OpenCode
    • Cursor Agent

    Berjalan dengan langganan yang sudah dimiliki.

  4. III

    13 jenis workspace

    Coding, konten & penjualan, laporan & keuangan, administrasi, riset, materi pelatihan, layanan pelanggan, HR, draf legal, toko online, terjemahan, proyek & acara, plus Kustom dengan tim dan cara QA buatan sendiri.

  5. IV

    Hasil langsung dilihat

    File hasil kerja bisa di-preview di tempat, termasuk Excel, CSV, Word, PDF, dan gambar, lalu di-download satu per satu atau sebagai zip.

  6. VI

    Aplikasi Windows, chat, terminal, Git

    Installer Windows dengan server di dalamnya. Tetap ada chat langsung dengan agent, terminal, penjelajah file, Git dan GitHub, serta login lokal tanpa akun pihak ketiga.

III · Workspace AI

Tim agent di satu canvas

Tersedia di Reaver4

  1. Kerjaan masuk ke Koordinator.
  2. Planner menyusun rencana dan urutan tim.
  3. Tim bekerja sesuai rencana, hasil diteruskan antar tim.
  4. QA/Audit memeriksa, yang tidak lolos kembali ke tim terkait maksimal dua kali.

Di Tampilan Lengkap, tim diatur di canvas: tarik panah untuk urutan kerja, pilih model per agent, beri skill, dan pantau pemakaian token.

V · Pasang

Cara pasang

Syarat Windows 10/11 64-bit dengan 8 GB RAM. Untuk server: Ubuntu 22.04+ atau Debian 12 atau macOS atau WSL2, 2 vCPU, 4 GB RAM, Node 22.

  1. Windows: download installer, klik dua kali, lalu ikuti wizard-nya.
  2. Server: siapkan VPS atau mesin lokal yang memenuhi syarat, lalu jalankan perintah terminal.
  3. Buka OpenLeira (atau alamat server di browser) dan buat akun pertama, yang otomatis menjadi admin.
  4. Sambungkan Claude Code, Codex, OpenCode, atau Cursor Agent yang sudah dilanggani.
