II · Fitur

Yang sudah bisa dipakai

  1. I

    Chat dari browser dan ponsel

    Sesi tetap berjalan di server saat tab ditutup atau koneksi putus, lalu bisa dilanjutkan dari perangkat lain.

  2. II

    Antrian dan interupsi

    Pesan baru masuk antrian selama agent bekerja, dan interupsi menghentikan langkah yang sedang berjalan untuk mengganti arah.

  3. III

    Penjelajah file server

    Telusuri dan buka file di server dari panel yang sama dengan chat.

  4. IV

    Skill per proyek

    Setiap proyek membawa kumpulan skill sendiri, jadi instruksi untuk satu repo tidak terbawa ke repo lain.

  5. V

    Empat provider

    Claude Code, Codex, OpenCode, dan Cursor Agent berjalan dengan langganan yang sudah dimiliki.

  6. VI

    Login lokal

    Akun dibuat dan diperiksa di server sendiri, tanpa akun Google, GitHub, atau pihak ketiga lain.

III · Workspace AI

Tim agent yang bekerja berfase Sedang dibangun

  1. Task masuk ke Orchestrator.
  2. Planner menyusun rencana dan urutan tim.
  3. Tim bekerja sesuai rencana, hasil diteruskan antar tim.
  4. QA/Audit memeriksa, yang tidak lolos kembali ke tim terkait maksimal dua kali.

Sudah berjalan di staging. Model dipilih per agent, dan tim bisa ditambah sendiri.

IV · Pasang

Cara pasang

Syarat: Ubuntu 22.04+ atau Debian 12 atau macOS atau WSL2, 2 vCPU, 4 GB RAM, Node 20.

  1. Siapkan VPS atau mesin lokal yang memenuhi syarat di atas.
  2. Jalankan perintah installer dari bagian atas halaman ini.
  3. Buka alamat server di browser dan buat akun pertama, yang otomatis menjadi admin.
  4. Sambungkan Claude Code, Codex, OpenCode, atau Cursor Agent yang sudah dilanggani.
